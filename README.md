# Hotel Reservation System

A sample Hotel Reservation System consisting of a .NET backend and an ASP.NET WebForms frontend. This repository contains the server-side API, data access and domain models, and a classic WebForms frontend used for user/admin interactions.

## Repository structure

- `backend/` — Backend solutions and projects (API, data access, models, services).
- `frontend/` — ASP.NET WebForms frontend project and related logic/models.

See the solution files under `backend/Backend.sln` and `frontend/Frontend.sln`.

## Prerequisites

- .NET SDK (check `backend/Backend/Backend.csproj` for the target framework). Install from https://dotnet.microsoft.com/
- Visual Studio (recommended) for opening and running the ASP.NET WebForms frontend (the frontend uses .aspx pages and Web.config).
- A SQL Server instance or other DB configured in `backend/Backend/appsettings.json` (if the project uses EF Core migrations).

## Backend — quick start

1. Open a terminal and navigate to the backend project:

```powershell
cd backend/Backend
```

2. Restore and build:

```powershell
dotnet restore
dotnet build
```

3. (Optional) If Entity Framework Core migrations are present and you want to update the database:

```powershell
dotnet tool restore
dotnet ef database update
```

4. Run the backend:

```powershell
dotnet run
```

5. Configure connection strings and settings in `appsettings.json` or `appsettings.Development.json` as needed.

The backend API typically exposes endpoints under `Controllers/` (for example `AuthController`, `HotelController`, `ReservationController`). Use the `Backend.http` file or a tool like Postman to inspect and test endpoints.

## Frontend — quick start

1. Open `frontend/Frontend.sln` in Visual Studio.
2. Build and run the project (F5) — Visual Studio will host the WebForms app in IIS Express by default.

Notes: The frontend is an ASP.NET WebForms application (`.aspx` pages). If you prefer to run it without Visual Studio, ensure IIS or IIS Express is configured and the project is built.
